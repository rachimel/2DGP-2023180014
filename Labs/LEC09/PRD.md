# Sonic Animation Viewer PRD

## 1. 목적
Sonic 스프라이트 시트의 모든 애니메이션을 확인하고, 각 프레임이 참조하는 이미지 영역을 편집하는 도구를 만든다.

## 2. 개발 범위
- Python을 사용하며, 그래픽 라이브러리는 pico2d를 우선한다.
- 사용자가 스프라이트 이미지를 직접 불러온다.
- 구현 결과물은 `sonic_animation_viewer.py` 단일 파일로 작성한다.
- 뷰어, 편집, 테스트 화면은 상단의 별도 `뷰어`·`편집`·`Play` 탭을 클릭하여 전환한다. 현재 탭을 시각적으로 표시한다.
- 두 화면은 논리적으로 분리하되, 같은 애니메이션 데이터를 공유한다.

## 3. 주요 기능

### 뷰어
- 스프라이트 시트에 정의된 모든 동작을 재생한다.
- 애니메이션 재생 속도는 기본 60fps이며, FPS 입력 칸에서 0.1~240fps 범위의 숫자와 소수를 입력하고 Enter 또는 적용 버튼으로 변경한다.
- 속도 변경 시 현재 프레임의 진행률과 1초 대기의 남은 시간을 유지한다. 잘못된 값은 적용하지 않고, Esc로 입력을 취소할 수 있다.
- 5회 재생 모드는 같은 애니메이션을 5회 재생한 후 1초 대기하고 다음 애니메이션으로 넘어간다. 버튼으로 이 모드를 켜고 끈다.
- 무한 반복은 별도의 버튼으로 켜고 끄며, 현재 애니메이션 리스트 전체를 반복한다. 마지막 동작이 끝나면 첫 동작부터 다시 재생한다.
- 애니메이션은 지정된 재생 화면 내부에 표시한다.
- 재생 화면 위에서 상하 마우스 스크롤로 확대·축소한다.
- 좌우 스크롤을 지원하는 마우스에서는 이미지 위치를 좌우로 이동한다.

### 애니메이션 선택
- 재생 화면 아래에 동작별 미리보기를 배치하고, 현재 재생 중인 동작을 가운데에 표시한다.
- 현재 동작의 미리보기를 노란색 테두리로 강조한다.
- 미리보기 영역 위에서 상하 스크롤로 동작을 변경한다.
- 마지막 동작과 첫 동작 사이에서도 순환하여 선택한다.
- 미리보기 항목을 좌클릭 드래그하여 애니메이션 목록의 순서를 변경한다. 대상 항목의 왼쪽 절반에 놓으면 앞에, 오른쪽 절반에 놓으면 뒤에 삽입한다.
- 드래그 중에는 삽입 위치를 표시하고, 상하 휠로 미리보기 목록을 넘겨 숨은 항목으로 이동할 수 있다. Esc 또는 미리보기 영역 밖에 놓으면 취소한다.
- 순서 변경 시 현재 동작과 프레임 진행률을 유지하며, 변경한 목록 순서로 재생하고 JSON에 저장한다.

### 편집
- 스프라이트 시트에서 현재 동작의 프레임 참조 영역을 수정한다.
- 시트 픽셀에 맞춘 그리드를 표시하며, 확대·축소와 시트 이동에 따라 정렬을 유지한다. 에디터 휠 확대·축소는 마우스 아래 시트 좌표가 같은 화면 위치에 유지되도록 시트를 평행이동한다. 간격은 별도 −/+ 버튼으로 1~256픽셀 범위에서 조절하며 휠 배율 변경으로 바뀌지 않는다. 마우스 아래 격자를 반투명 채우기와 테두리로 강조한다.
- 그리드 표시는 켜고 끌 수 있다.
- 피봇을 기준으로 동작과 프레임을 정의하고, 각 프레임의 표시 기준점을 지정한다.
- 체크박스로 영역을 선택하여 현재 프레임이 참조할 픽셀 영역을 지정한다.
- 각 프레임에는 하나의 참조 영역만 지정한다. 영역을 구분하는 구체적인 UI 방식은 구현 시 간단하게 정한다.
- 이미 지정된 영역은 좌클릭 후 드래그하여 이동할 수 있다.
- 선택한 영역은 Delete 키로 제거한다.
- 영역을 지정하는 동안에는 Outline(윤곽선)만 그리고, 지정이 완료되면 Fill(채우기)로 표시한다.
- 이전·다음 키프레임의 참조 영역을 반투명하게 표시하는 어니언 스킨 기능을 제공한다.
- 편집 결과는 뷰어에서 사용하는 공유 데이터에 반영한다.

### Play 게임 화면
- 시작점부터 골까지 이동하는 도형 맵을 제공한다. 적·장애물·가시·스프링은 추가 이미지 없이 Geometry로 표시한다.
- A/D 이동을 계속하면 가속하여 걷기에서 달리기로 바뀐다. W로 점프하고 Shift를 누르고 충전한 뒤 놓으면 스핀 대시한다.
- 지면 높이는 `PLAY_Y = 332`이며 점프·스프링에는 중력과 착지를 적용한다. 장애물 위에도 착지할 수 있다.
- 적은 점프하여 밟거나 스핀 대시로 처치한다. 적·가시에 일반 충돌하면 시작점으로 돌아가며 잠깐 무적 상태가 된다.
- 시작·정지·걷기·달리기·스핀 충전·대시·점프·제동·피격·골 이벤트에 애니메이션 이름 문자열을 연결하여 자동 재생한다. 실행 중 `이벤트 연결 설정` 창에서 이벤트를 선택하고 이름을 입력하거나 목록에서 고른다. JSON의 `event_bindings`로 저장하며 10개 순환 버튼은 사용하지 않는다.
- Space로 일시정지·재개하고 R 또는 다시 시작 버튼으로 맵과 적을 초기화한다. 카메라는 캐릭터를 따라간다.
- 공유 프레임·피봇 데이터와 설정한 FPS를 사용한다. 동작 연결은 JSON에 저장하며, 실제 게임의 위치·진행 상태는 저장하지 않는다.

## 4. 데이터 저장·불러오기
- 편집 데이터는 JSON 형식으로 export/import할 수 있어야 한다.
- 데이터에는 재생 속도, 스프라이트 이미지 참조, 애니메이션 목록과 순서, 각 동작의 프레임 순서, 프레임별 참조 영역과 피봇을 포함한다.
- import한 데이터로 편집 상태와 애니메이션 재생을 복원할 수 있어야 한다.

## 5. 개발 단계
커밋 기준은 단순하게 잡는다. 사소한 변경도 하나의 커밋으로 남길 수 있으며, 약 30개를 예상하고 여유 있게 진행한다. 개수를 강제하지 않고 필요하면 더 나눈다. 각 변경은 가능한 범위에서 실행·확인하고, 커밋 메시지는 한글로 작성한다.

개발 중에는 작은 기능을 완성하거나 주요 검증을 마칠 때마다 중간 보고한다. 보고에는 완료한 변경, 확인 결과, 다음 작업을 짧게 담고, 문제나 요구사항 해석의 변경이 생기면 바로 알린다.

## 6. 완료 기준
- Play 탭에서 이동·달리기·점프·스핀 대시와 충돌·스프링·골 도착을 플레이할 수 있고 상태에 맞는 동작이 자동 재생된다.
- 상단의 별도 탭으로 뷰어·편집 화면을 전환할 수 있고, 현재 탭을 다시 클릭해도 선택 상태가 유지된다.
- 편집 시트의 그리드가 확대·이동 후에도 이미지 픽셀 좌표에 맞게 표시되며, 표시 여부를 전환할 수 있다.
- 정의된 모든 동작이 설정한 재생 규칙대로 표시된다.
- 애니메이션이 입력한 속도로 재생되고, 프레임별 피봇이 표시 기준점으로 적용된다.
- 5회 재생 모드를 켜면 같은 동작을 5회 재생하고 1초 대기한 뒤 다음 동작으로 넘어간다. 버튼으로 모드를 끌 수 있다.
- 전체 반복을 켜면 마지막 동작 이후 첫 동작으로 돌아간다.
- 재생 영역과 미리보기 영역에서 스크롤이 각각 의도한 기능으로 동작한다.
- 현재 동작의 미리보기가 중앙에 표시되고 노란색 테두리로 강조된다.
- 미리보기 드래그로 목록 순서를 변경할 수 있고, 기존 선택·재생 상태를 유지하며, 변경한 순서가 재생과 JSON 복원에 반영된다.
- 프레임 참조 영역을 지정하고, 좌클릭 드래그로 이동하거나 Delete 키로 제거할 수 있다. 변경 결과를 뷰어에서 확인할 수 있다.
- 영역 지정 중에는 Outline만 표시되고, 지정 완료 후에는 Fill로 표시된다.
- 이전·다음 키프레임의 참조 영역을 반투명하게 확인할 수 있다.
- 각 프레임의 참조 영역은 하나로 제한된다.
- 편집 데이터를 JSON으로 export하고 다시 import했을 때 재생 속도, 애니메이션 목록·순서, 프레임 영역과 피봇이 복원된다.
- 위 기능의 구현이 단일 Python 파일에 포함된다.
