## 조작
- 상단 `뷰어`·`편집`·`Play` 탭 클릭: 화면 전환. 선택된 탭은 노란 밑줄로 표시하며, 현재 탭을 다시 클릭해도 선택 프레임을 유지한다.
- 뷰어: 기본 60fps 재생. FPS 입력 칸을 클릭해 숫자를 입력한 뒤 Enter 또는 적용 버튼으로 변경한다. 0.1~240fps 범위에서 소수도 지원한다. 입력 중 Esc 또는 다른 영역 클릭은 미적용 입력을 취소한다.
- 5회 재생 모드 ON이면 같은 동작을 5회 재생하고 1초 대기한 뒤 다음 동작으로 이동한다. OFF이면 한 번 재생하고 바로 다음 동작으로 이동한다.
- 목록 반복 ON: 마지막 동작 이후 첫 동작으로 돌아간다. OFF: 마지막 동작에서 멈춘다. 미리보기를 클릭하면 해당 동작부터 다시 재생한다.
- 미리보기 클릭·상하 휠: 순환 선택. 현재 동작은 가운데에 배치하고 노란 테두리로 표시한다.
- 미리보기 좌클릭 드래그: 애니메이션 순서 이동. 대상 항목의 왼쪽 절반에 놓으면 앞에, 오른쪽 절반에 놓으면 뒤에 삽입한다. 청록색 세로선으로 삽입 위치를 표시한다.
- 미리보기 드래그 중 상하 휠: 목록을 넘겨 숨은 항목으로 이동. Esc 또는 미리보기 영역 밖에 놓기: 순서 변경 취소.
- 재생 영역 상하 휠: 확대·축소. 좌우 휠: 이미지 좌우 이동.
- 편집 중 Left/Right 또는 이전·다음 버튼: 프레임 선택. 하단 미리보기: 동작 선택.
- 영역 지정 모드 체크 후 시트에서 좌클릭 드래그: 참조 영역 지정. 미지정 프레임은 체크하지 않아도 드래그로 지정할 수 있다.
- 지정 중에는 윤곽선만 표시하고, 마우스를 놓으면 반투명 채우기로 확정한다. 프레임당 영역은 하나로 제한한다.
- 지정된 영역 내부에서 좌클릭 드래그: 이동. 시트 경계를 벗어나지 않는다.
- `Delete`: 현재 프레임의 참조 영역 제거. `프레임 제거` 버튼은 프레임 자체를 제거한다.
- 시트 우클릭: 현재 프레임의 피봇 지정. 피봇은 참조 영역 내부의 좌표이며 기본값은 하단 중앙이다.
- 편집 영역 상하 휠: 시트 확대·축소. 중클릭 드래그: 시트 이동.
- 그리드 체크박스: 표시 켜기·끄기. −/+ 버튼으로 간격을 1~256픽셀에서 조절한다(기본 8픽셀). 휠 확대·축소와 독립적이며 시트 좌표에 정렬된다. 마우스 아래 격자는 청록색으로 강조하고 이미지 가장자리에서는 잘라 표시한다.
- 어니언 스킨 버튼: 이전·다음 프레임의 반투명 영역과 피봇 기준 겹침 미리보기 전환.
- FPS 입력 중 `Esc`: 입력 취소. 드래그 중 `Esc`: 지정·이동 취소. 그 외에는 프로그램 종료.
- JSON 저장·불러오기: 재생 속도, 이미지 참조, 동작·프레임 순서, 참조 영역, 피봇 복원.

뷰어와 편집 화면은 동일한 프로젝트 데이터를 사용한다. 편집 중에는 자동 재생을 멈추고, 뷰어로 돌아가면 선택한 동작의 첫 프레임부터 재생한다. 재생 모드 버튼을 바꾸면 현재 동작의 처음부터 재생한다.

미리보기를 누른 동안 재생을 잠깐 멈춘다. 단순 클릭은 해당 동작을 선택하고, 드래그 순서 변경은 기존 동작·프레임 진행률을 보존하여 이어서 재생한다. 편집 화면에서도 선택한 동작과 프레임을 유지한다. 드래그 중 휠로 넘긴 목록은 놓거나 취소하면 현재 선택한 동작을 중앙에 둔 상태로 돌아온다. 변경한 순서는 재생 목록과 JSON 저장에 반영된다.

재생 속도 변경은 현재 프레임의 진행률과 1초 대기의 남은 시간을 유지한다. 화면 갱신 목표는 60Hz이며 애니메이션 속도와 별도로 관리한다. 60fps를 넘는 재생 속도에서는 시간에 맞는 프레임을 표시하므로 일부 중간 프레임이 화면에 표시되지 않을 수 있다.

## Play 게임
시작점·골·적·장애물·가시·스프링을 도형으로 구성한 2600픽셀 맵을 플레이한다. 카메라가 캐릭터를 따라간다. 점프·스프링 요구사항에 따라 기존 고정 Y 데모를 중력·착지가 있는 게임으로 변경했다. 지면 표시는 `PLAY_Y = 332`다.

- A/D: 가속 이동. 계속 누르면 걷기에서 달리기로 전환.
- W: 지면·장애물 위에서 점프.
- Shift: 지면에서 스핀 충전. 놓으면 바라보는 방향으로 대시.
- 적: 점프하여 밟거나 대시로 처치. 일반 충돌·가시는 시작점 복귀 및 잠깐 무적.
- 노란 스프링: 닿으면 높이 튀어 오른다. 청록색 골에 도착하면 완료.
- Space: 일시정지·재개. R 또는 다시 시작: 위치·적·피격 횟수 초기화.
- 하단에는 현재 이벤트와 연결된 애니메이션 이름을 표시한다. 10개 순환 버튼은 제거했다. 코드의 `EVENT_ANIMATIONS` 또는 JSON의 `event_bindings`에서 이벤트를 애니메이션 이름 문자열과 연결한다. 예: `"jump": "동작 05"`. 이벤트는 `start`, `idle`, `walk`, `run`, `charge`, `dash`, `jump`, `brake`, `hurt`, `goal`이다.
- FPS 입력: 애니메이션 속도 변경. 물리 속도에는 영향을 주지 않는다.

동작 연결은 JSON의 `event_bindings`에 이름 문자열로 저장한다. 미리보기 순서를 바꿔도 이름으로 찾아 재생한다. 이름이 없으면 첫 동작을 표시하고 하단에 누락 상태를 알린다. 같은 이름이 여러 개면 첫 동작을 선택하므로 연결할 이름은 고유하게 유지해야 한다. 기존 `game_roles` 숫자 연결은 불러올 때 이름으로 변환하고, 연결 설정이 없는 JSON은 기본 연결을 적용한다. 게임 위치·진행·일시정지 상태는 저장하지 않는다. Play 진입·새 이미지·JSON 불러오기는 게임을 초기화한다.

## JSON
버전 1, 이미지 왼쪽 아래 좌표계를 사용한다. `fps`에 설정한 재생 속도를 저장하고 복원한다. 기존의 60fps JSON도 불러올 수 있다. 영역은 `[x, y, width, height]`, 피봇은 해당 영역의 왼쪽 아래를 기준으로 한 `[x, y]`다. 영역이 없는 프레임은 `rect: null`로 저장한다.

JSON은 원본 이미지를 포함하지 않고 경로를 참조한다. 가능하면 JSON 파일 위치에 대한 상대 경로로 저장하므로 원본 이미지와 경로 관계를 유지해야 한다. 저장 실패 시 기존 JSON을 보존하고, 불러오기는 데이터와 이미지 크기 검증을 마친 뒤에만 현재 프로젝트를 교체한다.
